# 🧹 Data Cleaning Practice Repository

This repository contains a collection of **end-to-end data cleaning practice notebooks** along with the datasets used in each exercise.
These notebooks demonstrate practical techniques to clean, preprocess, and prepare real-world datasets for analysis and modeling.

---

## 🧠 Skills & Concepts Covered

Each notebook focuses on a key part of the data cleaning lifecycle:

* Handling missing values

  * mean/median imputation
  * forward/backward fill
  * dropping thresholds

* Handling duplicates

* Outlier detection & treatment

  * IQR method
  * z-score method

* Data type conversions

  * datetime parsing
  * categorical encoding

* Feature scaling & normalization

* String cleanup

  * trimming whitespace
  * regex cleaning

* Exploratory data consistency checks

---

## 📥 Datasets Included

Feel free to download and practice with them independently.
Most datasets are synthetic or anonymized for learning purposes.

## 🚀 How to Use This Repository

1. Clone the repo

   ```
   git clone https://github.com/<your-username>/data-cleaning-practice.git
   ```

2. Install dependencies

   ```
   pip install -r requirements.txt
   ```

3. Open the notebooks in Jupyter or VS Code

   ```
   jupyter notebook
   ```

4. Follow each file for specific learning tasks and outputs.
